TransformerPath Grid Lab

A census simulator — frequency, UHV / 765 kV class, synchronous-area labels, isolated systems — run against the live grid records. Each scenario is COMPLETE, a percent, or NOT STARTED. This is not another 3D part model. Country Grid Lab is later. Independently live at /grid-lab.

50 Hz and 60 Hz worlds

The census records national frequency. Most of the world is 50 Hz; a smaller set — including North America, parts of the Americas, Saudi Arabia, Japan (split), South Korea and the Philippines — is 60 Hz.

6 min · Grid systems · NOT STARTED

UHV and 765 kV class

A 765 kV class grid is uncommon. The census records transmission voltage per operator — UHV / 765 kV is a structured voltage match, not a marketing label.

8 min · Grid systems · NOT STARTED

Synchronous areas

grids.json records a free-text `sync` label (Continental Europe, GCCIA, Isolated, …). It is not yet a controlled vocabulary — Grid Lab therefore asks you to read the label, not to invent a “synchronous-area total”.

6 min · Grid systems · NOT STARTED

400 kV class grids

400 kV (and nearby 380 / 400 / 420 kV) is the common extra-high-voltage transmission class outside UHV systems.

6 min · Grid systems · NOT STARTED

Isolated systems

An Isolated sync label means the census does not record a continental synchronous tie — islands, remote systems, or unlinked national grids.

5 min · Grid systems · NOT STARTED

Highest voltage in the census

The highest transmission voltage in this census is derived from operator voltage strings — never invented.
