Affiliate disclosure

Some TransformerPath pages link to travel search tools. When a link is an affiliate link, TransformerPath may earn a commission if you book. That does not change the price the provider charges. TransformerPath does not quote hotel rates, airfares, insurance premiums or eSIM prices.

What is on the site

The Travelpayouts partner marker in this project is 736890. It is the same marker already used by the Hotellook hotel links and by the Kiwi flight link in the events calendar. The Travelpayouts project id (trs) on those flight links is 548938.

  • Event and exhibition pages with a confirmed upcoming city and dates include a hotel search form (Hotellook) prefilled with that city and those dates, and a flight search. The flight button opens the Kiwi Travelpayouts click until you enter a departure airport code. With a three-letter departure code it opens an Aviasales search for that airport, the event airport and those dates.
  • The events calendar uses the same hotel and flight links, as compact buttons on each confirmed upcoming card. The exhibitions index does not carry a generic hotel or flight button.
  • Things to do on those cards uses the existing KKday short link.
  • Factory acceptance, site-visit, factory and market pages link to VisitorsCoverage for travel insurance and Airalo for a travel eSIM. On 14 October 2026 those campaigns were not subscribed for marker 736890, so the buttons open the provider homepages directly and are not sponsored links. A build can turn on tracked links by setting TP_INSURANCE_URL or TP_ESIM_URL to an https URL from the Travelpayouts dashboard.

These blocks are not placed on the homepage hero, the privacy or terms pages, or checkout and claim pages. A link to this page is in the footer.

Sub-IDs

Each placement has its own sub-ID so clicks can be separated. Travelpayouts allows letters, digits and underscores in a sub-ID, so hyphens in a page slug are written as underscores. Examples: event_wetex_hotel, event_wetex_flight, event_wetex_activities, trip_fat_vs_sat_insurance, trip_uae_esim.

Hotel links send marker=736890.<sub_id> and sub_id=. Flight clicks send shmarker=736890.<sub_id> on the Kiwi campaign (campaign 111, promo 3413).

Scripts

Hotel forms and the insurance and eSIM buttons are ordinary HTML. They do not wait for a third-party script. The Travelpayouts loader (emrldtp.com, project 548938) is not in the page HTML. tp-affiliate.js loads it only after cookie consent, and only when a hotel or flight block is near the viewport or you interact with it. Each block reserves a minimum height so the loader does not move the page.

Where to see click counts

Google Analytics 4. Property G-98Q0V62L72. A click on a placement fires the event affiliate_click with parameter sub_id (and placement: hotel, flight, activities, insurance or esim). The tag loads only on transformerpath.com after the visitor accepts cookies. In GA4: Reports → Engagement → Events → affiliate_click. The same event appears in Realtime while you test, and in Explorations if you break it down by the sub_id parameter.

Travelpayouts. Reports → Performance, grouped or filtered by SubID. Hotel searches use the marker sub-ID. Flight clicks that go through the Kiwi campaign use the same sub-ID on shmarker. Direct VisitorsCoverage and Airalo visits do not appear there until TP_INSURANCE_URL or TP_ESIM_URL is set.

The events calendar also stores a click log in this browser only (localStorage key tp-aff-clicks, including sub). That log is not the site-wide count. Use GA4 and Travelpayouts for that.
